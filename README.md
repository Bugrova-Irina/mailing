# Интернет-магазин на Django
python manage.py runserver - запуск веб-приложения. Ctrl+C - остановка сервера.

python manage.py createadmin - создание суперпользователя

python manage.py send_mailings - запуск рассылки через командную строку

python manage.py export_users --output=my_users.json - экспорт пользователей
приложения в файл json

python manage.py add_users - создание тестовых пользователей

ВАЖНО!!! Регистрация пользователя на сайте происходит через письмо с подтверждением, которое
отправляется на email пользователя. Если регистрируетесь под вымышленным email, в админке под
администратором поставьте у этого пользователя с вымышленным email галочку "Active", чтобы
можно было потом под ним авторизоваться на сайте.
## Описание:

Веб-приложение для рассылки писем списку пользователей. В приложении настроено
кеширование страниц со списком клиентов, писем, рассылок, попыток рассылок. Во
время работы приложения необходимо запускать Redis. По умолчанию в приложении
есть 4 типа пользователей: суперадмин, менеджеры, обычные пользователи,
неавторизованные посетители. Неавторизованные пользователи могут видеть
общую статистику рассылок на главной странице, в остальных разделах им доступна
только форма авторизации, в верхнем меню - кнопка регистрации для новых
пользователей. Менеджеры видят список всех клиентов, рассылок, сообщений, пользователей.
Они могут редактировать и удалять только тех, кого создали сами. Могут менять статус
любой рассылки, могут блокировать пользователей сервиса. Обычные пользователи видят
список только своих клиентов, рассылок, сообщений, свой профиль и могут их редактировать.
Суперадмин может всё.

## Требования к окружению:

Установите:
 - python 3.13.0
 - Poetry
 - Django
 - Pillow
 - python-dotenv
 - psycopg2 или psycopg2-binary
 - redis
В качестве базы данных используется PostgreSQL

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/Bugrova-Irina/coursework_django_web/
```
